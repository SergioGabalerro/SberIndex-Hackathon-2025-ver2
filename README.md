# 🚀 SberIndex Hackathon 2025 - Аналитический AI-Ассистент

## 📋 Описание проекта

Интеллектуальный ассистент для анализа данных 🤖, разработанный для хакатона SberIndex 2025. Основная фишка проекта заключается в борьбе с галлюцинациями при анализе данных ✨: вместо того чтобы ИИ придумывал выводы, система генерирует Pandas код на основе языковых запросов аналитика, выполняет его и делает выводы на основе реальных результатов 📊.

### 🎯 Ключевые возможности

- **Генерация Pandas кода** 🐼 из естественно-языковых запросов аналитиков
- **Защита от галлюцинаций** 🛡️: все выводы делаются только на основе реально выполненного кода
- **Валидация статистики** 🔍: система сообщает, если статистические результаты выглядят странно или подозрительно
- **Автоматический анализ данных** ⚡ с проверкой корректности

## 🏗️ Архитектура решения

```
Запрос аналитика (естественный язык) 💬
         ↓
Генерация Pandas кода через LLM 🧠
         ↓
Выполнение кода на реальных данных 💻
         ↓
Проверка результатов на странности 🔎
         ↓
Формирование выводов на основе результатов ✅
```

## 💡 Принцип работы

### 1. Обработка запроса
Аналитик задает вопрос на естественном языке:
```
"Покажи среднюю стоимость заказов по городам за последний месяц"
```

### 2. Генерация кода
Система генерирует соответствующий Pandas код:
```python
df.groupby('city')['order_amount'].mean()
```

### 3. Выполнение и валидация
- Код выполняется на реальных данных
- Результаты проверяются на адекватность
- Выявляются подозрительные паттерны (аномалии, пропуски, странные распределения)

### 4. Формирование ответа
На основе реальных результатов формируется ответ с предупреждениями о возможных проблемах:
```
Средняя стоимость заказов:
- Москва: 2,500₽
- Санкт-Петербург: 2,100₽

⚠️ Внимание: В данных обнаружены выбросы в Москве (3 заказа > 50,000₽)
```

## 🔍 Защита от галлюцинаций

### Проблема
Классические LLM-аналитики часто "придумывают" выводы и статистику.

### Решение
1. **Никаких прямых ответов** - только через код
2. **Проверка результатов** - валидация на странности
3. **Прозрачность** - пользователь видит и код, и результаты
4. **Честность** - система признается, если не уверена в результатах

## 📈 Примеры использования

### Базовый анализ
```
Вопрос: "Сколько заказов было в декабре?"
Код: df[df['date'].dt.month == 12]['order_id'].count()
Результат: 1,523 заказа
```

### Анализ с предупреждением
```
Вопрос: "Какой средний чек по категориям?"
Код: df.groupby('category')['amount'].mean()
Результат: 
- Электроника: 15,000₽
- Одежда: 3,500₽

⚠️ В категории "Электроника" 60% значений отсутствуют
```
